常见问题Frequently asked questions

怎么转换文件？How do I convert a file?

在访达（Mac）或文件资源管理器（Windows）里按住鼠标拖动一个文件，拖动的同时按住 Shift，鼠标旁边会弹出一排格式按钮。往想要的格式方向拖一下，松开鼠标，转换好的新文件就保存在原文件旁边，原文件不会被改动。 Start dragging a file in Finder (Mac) or File Explorer (Windows) and, while still holding the mouse button, hold Shift. Round format buttons appear next to the pointer. Move toward a format and let go. The converted copy is saved next to the original, which is never changed.

想用工具（裁剪、压缩、抠图、提取文字等）：Mac 按住 Option + Shift，Windows 按住 Ctrl + Shift。 For tools (crop, compress, remove background, extract text and more), hold Option + Shift on Mac or Ctrl + Shift on Windows.

按住 Shift 拖文件，按钮没有出现I hold Shift while dragging, but no buttons appear

1. 确认 FileFlipper 正在运行：Mac 看屏幕右上角菜单栏有没有 ◎ 图标，Windows 看右下角通知区域（可能藏在 ^ 里）。没有的话，重新打开 FileFlipper。 1. Make sure FileFlipper is running: on Mac, look for the ◎ icon in the menu bar at the top right; on Windows, in the notification area at the bottom right (it may be under ^). If it isn't there, open FileFlipper again.

2. 点这个图标，确认「启用」前面有勾。2. Click the icon and make sure Enabled is checked.

3. 要先按住鼠标开始拖动，再按 Shift。只选中文件按 Shift 不会弹出按钮。拖文件夹也不会弹出。3. Start dragging first, then hold Shift. Pressing Shift with a file only selected does nothing, and folders aren't supported.

Mac提示需要文件夹权限It asks for folder access

Mac App Store 版的 App 需要你允许，才能把文件保存到某个文件夹。弹出窗口时选择你的个人文件夹（带小房子图标的那个），点「授权」，以后就不会再问了。也可以随时点菜单栏图标 →「允许访问个人文件夹…」。 Apps from the Mac App Store need your permission before saving into a folder. When the window appears, choose your Home folder (the one with the house icon) and click Grant Access; it won't ask again. You can also do this any time from the menu bar icon → Allow Home Folder….

打开时提示「无法验证开发者」或「Windows 已保护你的电脑」“Cannot verify the developer” or “Windows protected your PC”

Mac从网站下载的版本第一次打开时：去「系统设置 → 隐私与安全性」，往下找到 FileFlipper，点「仍要打开」。从 Mac App Store 安装的版本不会有这个提示。 For the version downloaded from this website, on first launch: open System Settings → Privacy & Security, scroll down to FileFlipper and click Open Anyway. The Mac App Store version never shows this.

Windows点「更多信息」→「仍要运行」。Click More info → Run anyway.

支持哪些文件？Which files are supported?

图片（JPG、PNG、HEIC、WEBP、TIFF、GIF、BMP）、PDF、文档（Word、RTF、ODT、HTML、TXT、Markdown）、PPT（.pptx）、Excel（.xlsx）、视频和音频。所有文档都可以一键转成 Markdown。旧版的 .ppt / .xls 请先用 Office 另存为新格式。 Images (JPG, PNG, HEIC, WEBP, TIFF, GIF, BMP), PDF, documents (Word, RTF, ODT, HTML, TXT, Markdown), PowerPoint (.pptx), Excel (.xlsx), video and audio. Any document can be turned into Markdown. Please save old .ppt / .xls files in the new format first.

我的文件会被上传吗？Are my files uploaded anywhere?

不会。FileFlipper 不联网，所有转换都在你自己的电脑上完成，不收集任何数据。详见隐私政策。 No. FileFlipper never connects to the internet; every conversion happens on your own computer and no data is collected. See the privacy policy.

界面是中文的吗？Which languages does it support?

支持简体中文和英文，会跟随电脑的系统语言自动切换。English and Simplified Chinese. FileFlipper follows your computer's system language.

怎么卸载？How do I uninstall it?

Mac点菜单栏图标 →「退出 FileFlipper」，再把「应用程序」里的 FileFlipper 拖到废纸篓。Click the menu bar icon → Quit FileFlipper, then drag FileFlipper from Applications to the Trash.

Windows「设置 → 应用 → 已安装的应用」里找到 FileFlipper，点「卸载」。Settings → Apps → Installed apps → FileFlipper → Uninstall.
